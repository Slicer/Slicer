# Layer Displayable Manager

Slicer Layer DM is a Module simplifying the creation of new display
and widget components in the 3D Slicer views.

The module builds on the displayable manager system. Developers unfamiliar with this system can find a summary of its
architecture and behavior in the [Displayable Managers Overview](../displayable_managers_overview.md).
